# 设计规范

Super Kanban 的界面目标是：**像 DSH 自带功能一样克制**。文字与留白承载层次，颜色只用于真正的语义例外；操作少而直达。

## 1. 设计原则

1. **单色为底，克制的强调色（Restrained accent）**：界面以文字层级与背景层次组织信息；彩色只用于小面积语义标记——状态点、细进度线、优先级小字、类型图标与关键链接，禁止色块、渐变与光晕。
2. **信息分层，关键事实优先**：卡片只保留三层信息（标题 / 元信息 / 进度线）；抽屉先给结论与关键事实，完整证据默认折叠。
3. **一屏一主操作，常用动作外放**：每块区域只保留一个主按钮。扫描、设置和在右侧栏打开等动作常驻，页头「⋯」收纳扫描详情和导出。
4. **与 DSH 同源**：字体、字号、圆角、间距、描边全部对齐 DSH 原生规范，深浅色跟随系统。
5. **安静的成功、明确的失败**：轮询静默、无 loading 闪烁；失败用文字与 toast 说明，不用大面积红色。

## 1.1 强调色与状态标记（v0.4）

颜色只在「点 / 细线 / 小图标 / 小字」级别出现，用同一套语义色贯穿看板、抽屉与右栏：

| 语义 | 颜色 | 用法 |
| --- | --- | --- |
| 进行中 / 品牌 | 品牌蓝（`--dsw-alias-state-business-primary`） | 状态点、3px 进度线（75% 透明混合）、抽屉状态文字、关键事实 progress 图标、会话链接、「AI」标记（65%） |
| 受阻 / 需注意 | 琥珀（warning） | 状态点、进度线（75%）、`⚠ 问题数`、P1 优先级字、类型图标 |
| 错误 / 高优 | 错误红（error） | P0 优先级字、severity=high 的问题、错误文案 |
| 已完成 | 绿（success） | 完成卡状态点（55%）；完成卡**不绘制进度线** |
| 待办 / 中性 | 文字色 40–45% | 待办状态点、P2/P3 优先级、产物数、元信息 |

卡片固定三层：标题行（状态点 + 13px/600 标题 + 右侧 AI/规则标记）→ 元信息行（工作区 · 时间，右侧为优先级 / 问题数 / 产物数 / 子任务进度）→ 3px 状态色进度线；1680 宽下卡片约 76–80px，1280 宽下 ≤100px，行内不换行。

- **完成卡**：整卡 0.7 不透明度、标题字重 500，**不绘制 3px 进度线**（去掉整条彩色线，只保留绿色状态点与元信息）。
- **归档卡**：仅在筛选「含归档」时出现，标题行右侧显示 10px「已归档」小标签；窄侧栏（单列档）隐藏该标签，避免挤压标题。
- **侧栏工作区下拉**：右侧栏在任何档位都保留工作区筛选下拉（宽档也显示），不再被宽度规则隐藏。

## 2. DSH 设计基准

以下数值取自 DSH 桌面端实际界面，是插件视觉的唯一参照：

| 项 | 值 |
| --- | --- |
| 字体 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif` |
| 页面标题 | 20px / 500 |
| 区块标题 | 15–16px / 600 |
| 列表项标题 | 14px / 600 |
| 说明文字 | 12–13px / 400，约 65% 文字色 |
| 元信息 | 11–12px / 400，约 45% 文字色 |
| 按钮 | 高 32–38px，圆角 8–12px；主按钮为中性填充，次按钮为描边或 ghost |
| 圆角 | xs 4 / sm 8 / md 12 / lg 16 / xl 20 |
| 描边 | 0.5px hairline；列表区域优先用背景层次替代整块描边 |
| 间距 | 8pt 网格；页面内边距 28–32px；行高 36–44px；区块间距 24–32px |
| 动效 | 0.1–0.3s，`cubic-bezier(.4,0,.2,1)`，仅使用 opacity / transform |
| 侧栏项 | 14px、高 36、圆角 12 |

颜色全部通过 DSH 设计 token 获取（`--dsw-alias-bg-*`、`--dsw-alias-label-*`、`--dsw-alias-border-*`、状态色等），并用 `color-mix` 派生透明层级；禁止写死黑白之外的色值、禁止外部字体与图片。

## 3. 视觉规则（硬性）

1. **允许的彩色**（与 §1.1 一致）：
   - 状态圆点：进行中=品牌蓝、受阻=琥珀、完成=绿（55%）、待办=文字色 40%；
   - 卡片 3px 进度线：进行中=品牌 75%、受阻=琥珀 75%、待办=文字色 20%；**完成卡不绘制进度线**（只保留绿色状态点）；
   - 优先级小字：P0=错误红、P1=琥珀、P2/P3=文字色 45%；
   - 类型图标（问题/产物/子任务/关键事实/session）、会话链接、AI/规则标记。
   - 其余一律用文字层级表达：primary 100% / secondary 65% / tertiary 45%。
   - 禁止：彩色卡片底/整块色块、渐变、光晕、彩色进度百分比文字。
2. **字号收敛为 5 档**：20（页面标题）/ 15（区块标题）/ 13（正文与卡片标题，600）/ 12（说明）/ 11（元信息）。不使用 9–10px 正文（状态点旁数字 ≥10px）。
3. **卡片扁平化**：背景 `bg-layer-1`（或 base + 0.5px hairline），圆角 12，内边距 11–14，卡片间距 8px；静止态无阴影；hover 仅 1px 上移 + 轻阴影/边框变化，不做发光或大幅位移。
4. **去掉盒子**：统计用一行文字，不用彩色 KPI 卡；AI 研判是普通段落，不是彩色提示框；筛选用文字按钮 / 下拉，不用彩色 chips。
5. **一屏一主操作**：看板头部的主按钮是「新建」，抽屉底部的主按钮是「继续此任务」或「验收产出」。
6. **层次靠留白与字重**：区块间距 ≥24px；分隔线只用 0.5px 横线且仅用于抽屉内分节。
7. **深浅色一致**：所有颜色来自 token 或由 token 派生；不出现只在单一主题下可读的颜色。

## 4. 布局与信息架构

### 4.1 全页看板

```
任务看板  12 项 · 3 进行中 · 1 受阻 · 5 完成      [搜索] [扫描] [设置] [右侧栏] [新建] [⋯]
[待处理] [看板] [列表] [层级] [产出] [维护]                         [工作区] [8 / 12] [筛选]
────────────────────────────────────────────────────────
● 待办 2          ● 进行中 3         ● 受阻 1          ● 已完成 4 ︿
 卡片              卡片              卡片              卡片
```

- 第一行左侧是标题与统计，右侧是搜索和常用操作。空间紧张时统计收为总数，悬停仍可看状态分布。
- 第二行左侧切换视图，右侧选工作区、查看筛选结果数量和打开筛选。窄栏将视图收为下拉，搜索移入筛选弹层。
- 扫描按钮悬停显示完整结果。扫描中显示进度，点击可取消；失败时按钮显示「重试」，悬停可看原因。
- 每列独立纵向滚动，每页 30 张卡。超过一页时列底显示当前范围和翻页按钮，翻页回到列顶。切换筛选后从第一页开始。
- 点击「已完成」列头折叠或展开。折叠后保留列名与计数，仍可拖入任务。全页和侧栏分别记住折叠状态。
- 「⋯」可直接跳到维护视图查看扫描详情，也能导出 JSON。空态提供「立即扫描」。

### 4.2 卡片（高度 ≤100px，三层信息）

```
● 标题（13px/600，最多 2 行）                           [已归档] AI
工作区 · 3 小时前                  P0 ⚠1 ▤3 ✓5/8      ← 12px 元信息 + 11px 指标
进度线（3px，按状态着色；完成卡不显示）
```

- 只保留三层信号：**标题行**（状态点 / 标题 / 归档标记 / AI 或规则标记）、**元信息行**（工作区 · 时间 + 优先级 / 问题数 / 产物数 / 子任务进度）、**3px 状态色进度线**。
- 不显示目标摘要、标签、彩色徽标底；优先级只用小字颜色，问题/产物/子任务只用 10px 类型图标 + 数字。
- 完成态卡片保留标题与产出定位所需的对比度，标题字重 500。保留状态点并隐藏进度线。
- 归档卡：「已归档」10px 中性标签（窄侧栏隐藏）；仅「含归档」筛选下出现。
- 受阻 / 问题：状态点与进度线为琥珀色；高优问题数字用错误红。
- 窄侧栏（单列档）：元信息保留「短工作区 · 时间 · 优先级」，压缩指标与归档标签。
- 卡片和任务行都可通过右键、Shift+F10 或「⋯」打开快捷菜单。菜单提供查看详情、跳转来源会话、复制标题、置顶、归档和移动状态。

### 4.3 任务抽屉（参照 DSH 文档预览面板）

- 宽 520–560px；背景 `bg-layer-1`；左侧 0.5px hairline；无整屏模糊遮罩。
- 头部 48px：关闭 / 返回 + 「任务」小字 + 标题（15px/600，可两行）+ 右上「⋯」。
- 内容从任务概览开始，依次显示状态与完成依据、目标、验收条件、当前信号、主交付物和人工验收入口。等待审批、失败、依赖和可能同时修改可回到各自来源。
- 主交付物优先选择最新可用的明确交付文件。只有修改记录时显示「最近修改文件」。其他文件与失效记录折叠。点击文件名进入 DSH 预览，悬停显示来源与路径。文件菜单支持复制文件名和路径，在 DSH 宿主提供桌面能力时可用默认应用打开或在文件管理器中定位。失效文件仍可复制。
- 底栏「⋯」根据视口空间选择朝上或朝下展开，避免被抽屉裁切。任务归档成功后自动关闭抽屉，恢复后可继续查看详情。
- AI 研判默认折叠。标题保留引擎、模型、研判时间和时效提示。展开后显示完整理由。来源会话有新活动时才标记「可能已过期」。
- 关键事实默认 3 条，子任务默认 8 条，可展开、添加或从主会话导入待办。问题管理和建议下一步各自折叠，问题行提供来源与解决动作。
- 会话与任务关系、其他文件、活动与证据、历史在概览下方。活动与证据最近在前，支持按来源会话筛选。已知序号以 `#N` 标示，导航回到相应会话。
- 抽屉右上「⋯」菜单：编辑任务 / **重新研判** / 锁定或解锁字段 / 归档或恢复 / 删除任务。
  「重新研判」调用 `task.analyze`：只重判当前这张卡；扫描进行中给出提示；AI 不可用或超预算自动用规则重判，
  成功后 toast 显示引擎与本次调用/tokens。
- 底部固定操作条的主按钮按状态显示「继续此任务」或「验收产出」，另有「打开会话」与更多操作。
- 编辑态才出现「保存 / 取消」，展示态不铺表单控件；编辑草稿在后台轮询/扫描/重新研判后保留，
  并显示琥珀提醒「后台已更新；保存将覆盖 AI 的新结果」。
- 关闭：×、Esc、点击外部、浏览器返回手势均可。

### 4.4 「继续此任务」弹窗

- 宽 520px；标题 15px/600。
- 工作目的支持执行、排障、验收和交接。可选关联会话或新会话，关联多个会话时显示目标选择器。验收默认使用主交付物的来源会话。
- 提示词 textarea：等宽 12px、`bg-base`、0.5px 边框、圆角 8、约 8 行。
- 底部：ghost「取消」「仅复制」「AI 润色」+ 主按钮「放入会话」；说明文字 11px tertiary。
- 草稿带验收条件、未完成项、交付物与来源。保留用户编辑及目标会话已有草稿，确认实际放入后关联新会话，由用户自己发送。

### 4.5 右侧栏形态

- 无品牌头。第一行是统计与常用操作，第二行放视图、工作区、当前会话范围和筛选。
- 窄栏用视图下拉和状态分段切换单列。「已完成」分段可直接查看完成任务，长列可独立滚动和翻页。
- 状态切换用 DSH 视图 tab 文字样式，不做彩色胶囊。
- 三档自适应：
  - **窄（约 420px）**：单列卡片 + 状态分段切换（卡片只留标题与进度线）；
  - **中（约 500–740px）**：2×2 列或紧凑多列；
  - **宽（≥740px）/ 全屏**：四列完整看板。
- 抽屉在侧栏内覆盖整个面板，并带返回箭头。

### 4.6 设置弹窗

- 沿用现有 DSH 风格弹窗：宽约 560–640px，`max-height` 约视口 84%，内容区纵向滚动，底部常驻「保存设置 / 取消」；
  不引入彩色区块、KPI 卡或大图标。
- 自上而下分节（每节一行 `.sk-settings-row`，行高 36–44；模型节为全宽 block）：
  1. **AI 联网研判** 开关 + 说明（文案：「使用 DSH 配置的模型（含第三方）分析会话摘要」）。
  2. **AI 研判模型**（全宽 block，v0.5 新增）：
     - 标题 12px/600 + 说明 11px tertiary：“默认跟随 DSH 的默认模型；也可以指定一个已在 DSH 中配置的模型”；
     - 控件行：原生 `<select>`（`flex:1; min-width:0`，超宽文本 `text-overflow:ellipsis`，完整值放 `title`）
       + 右侧 28×28 刷新图标按钮（`aria-label="刷新模型目录"`）；
     - 选项：首项「跟随 DSH 默认」，其余按 provider `<optgroup>` 分组（显示模型名）；已保存模型不在目录时
       单独一组「已保存（目录中未找到）」；
     - 常驻一行引导（11px tertiary）：「第三方模型与 API Key 在『DSH 设置 → 模型』中配置；看板只读取已配置的
       模型，不保存凭证。」
     - 六态：加载中（`aria-busy`，不阻塞其它设置项）/ 刷新中 / 就绪 / 空目录 / 旧 DSH 不支持 / 读取失败（附
       「重试」文本按钮）。空态必须区分「没有 provider」「有 provider 但无模型（多为未配置凭证）」
       「provider 读取失败」，不能把失败误报成未配置；警告只用琥珀文字，不用彩色提示框。
     - 选中非官方 provider 时，说明行追加安静提示：「AI 研判会把会话压缩摘要发送给该模型服务商」。
  3. 自动扫描 / 扫描间隔 / 初始扫描范围（现状；顺序与 `client.js` 实现一致）。
  4. **AI 预算 · 单次扫描上限**：单下拉 `自动（推荐）/ 固定 20 / 固定 40 / 固定 80 / 固定 150`；
     当前值不在标准档时前置「固定 N 次」；`40` 不标注「默认」（默认是「自动」）。
  5. **AI 预算 · 每日上限**：沿用现有档位；说明补「每日预算单位上限（不是硬成本上限）」。
  6. **今日 AI 用量**（两行 + 一行小注，11–12px）：`今日 12/150 次 · 剩余 138 次 · tokens 5.1k` /
     `上次扫描：3 次调用 · 5.1k tokens · 8.2s`；剩余不足或耗尽用琥珀文字说明，不加进度条与徽标。
  7. 显示与入口（现状）。
  8. 排除工作区（现状）。
  9. 隐私说明（现状位置）：文案更新为「AI 研判请求经 DSH 发送给你配置的模型服务；第三方模型会收到压缩摘要；
     看板无遥测」。
- 420px 侧栏形态：模型 block 上下堆叠（label 一行、控件行一行），select 不横向溢出；弹窗整体纵向滚动。
- 无障碍：select 用 `aria-labelledby` 指向可见标题、`aria-describedby` 指向说明行；刷新按钮是独立 tab 停点
  （在 select 之后），刷新完成不移动焦点；状态播报用 `role="status" aria-live="polite"` 的视觉隐藏节点，
  可见说明行不重复播报。
- 弹窗变高只允许内容区滚动，footer 保存按钮始终可见；不新增遮罩模糊或入场动画（遵守降低动效偏好）。

## 5. 响应式与尺寸

| 场景 | 宽度 | 要求 |
| --- | --- | --- |
| 全页看板 | 1680px | 四列、无横向溢出，卡片约 76–80px |
| 全页看板 | 1280px | 四列可用，卡片高度 ≤100px，标题最多两行 |
| 窄窗口看板 | 390px | 两行页头、单列按状态切换，筛选内可搜索，顶部可新建 |
| 右侧栏 | 420px | 单列 + 状态分段，标题不截断到不可读 |
| 右侧栏 | 756px | 紧凑四列或分档布局 |
| 右侧栏全屏 | 视口宽度 | 与全页看板一致，可退出 |

全页和右侧栏独立记忆视图与筛选。看板适合按状态流转，列表支持批量管理，层级按工作区与父子任务浏览。待处理视图突出决策、阻塞和待确认任务，产出视图支持返回来源任务与打开文件。维护视图承载存储健康、忽略清单、备份恢复和撤销操作。

「待处理」入口的数字按当前筛选范围内的任务计数。真实待交互请求优先，一张卡下可列出多个来源会话及各自的打开动作。会话运行情况与任务阶段并列展示。普通轮次结束显示「待确认进度」，有可用的明确交付物或会话完成依据与人工验收条件时显示「待验收」。窄栏允许来源标题自然换行，按钮保留文字与键盘焦点。

会话头部打开的右侧栏优先展示当前会话。续做支持执行、排障、验收和交接。插件依据宿主确认结果放置草稿，已有草稿保留，发送由用户决定。

## 6. 交互规范

| 交互 | 规则 |
| --- | --- |
| 卡片点击 | 打开抽屉；拖拽换列时原卡片半透明，目标列 1px 边框高亮 |

## 7. 可读性与无障碍

- 正文对比度 ≥ 7:1，按钮文字 ≥ 4.5:1（浅色与深色都验证）。
- 焦点环使用 DSH focus token，键盘可完整操作。
- 浮层（抽屉、设置、「继续此任务」、「新建任务」）使用 `role="dialog"` + `aria-modal="true"` +
  `aria-labelledby`；打开时焦点进入首个可操作元素，`Tab` 在浮层内循环（焦点陷阱），`Esc`
  分层关闭（先关闭嵌套浮层 / 退出编辑，最后才关闭抽屉）并把焦点还给触发元素。
- 异步状态（生成提示词、保存、扫描）用 `role="status"` / `aria-live="polite"` 播报，不打断输入。
- 可勾选或切换的按钮提供 `aria-pressed`，分段单选使用 `radiogroup` + `aria-checked`。窄栏状态标签支持方向键、Home 和 End。
- 菜单用方向键选择，Enter 执行，Esc 收起并还原焦点。抽屉菜单按 Tab 收起后，焦点继续在抽屉内移动。
- 尊重 `prefers-reduced-motion`：所有动效在减少动效偏好下关闭。
- 状态不只靠颜色：受阻 / 错误同时有文字说明；纯图标的按钮必须带 `aria-label`。
- 中文优先排版：标题不强制英文字体；数字与代码用等宽字体 token。
