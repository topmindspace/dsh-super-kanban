# 设计规范

Super Kanban 的界面目标是：**像 DSH 自带功能一样克制**。文字与留白承载层次，颜色只用于真正的语义例外；操作少而直达。

## 1. 设计原则

1. **单色优先（Monochrome first）**：界面以文字层级与背景层次组织信息，彩色只出现在状态点与错误 / 受阻等语义例外上。
2. **信息分层，关键事实优先**：卡片只保留三层信息；抽屉先给结论与关键事实，完整证据默认折叠。
3. **一屏一主操作**：每块区域只保留一个主按钮，其余动作收进图标或「⋯」。
4. **与 DSH 同源**：字体、字号、圆角、间距、描边全部对齐 DSH 原生规范，深浅色跟随系统。
5. **安静的成功、明确的失败**：轮询静默、无 loading 闪烁；失败用文字与 toast 说明，不用大面积红色。

## 2. DSH 设计基准

以下数值取自 DSH 桌面端实际界面，是插件视觉的唯一参照：

| 项 | 值 |
| --- | --- |
| 字体 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif` |
| 页面标题 | 20px / 500 |
| 区块标题 | 15–16px / 600 |
| 列表项标题 | 14px / 600 |
| 说明文字 | 12–13px / 400，约 65% 文字色 |
| 元信息 | 11–12px / 400，约 45% 文字色 |
| 按钮 | 高 32–38px，圆角 8–12px；主按钮为中性填充，次按钮为描边或 ghost |
| 圆角 | xs 4 / sm 8 / md 12 / lg 16 / xl 20 |
| 描边 | 0.5px hairline；列表区域优先用背景层次替代整块描边 |
| 间距 | 8pt 网格；页面内边距 28–32px；行高 36–44px；区块间距 24–32px |
| 动效 | 0.1–0.3s，`cubic-bezier(.4,0,.2,1)`，仅使用 opacity / transform |
| 侧栏项 | 14px、高 36、圆角 12 |

颜色全部通过 DSH 设计 token 获取（`--dsw-alias-bg-*`、`--dsw-alias-label-*`、`--dsw-alias-border-*`、状态色等），并用 `color-mix` 派生透明层级；禁止写死黑白之外的色值、禁止外部字体与图片。

## 3. 视觉规则（硬性）

1. **允许的彩色**：
   - 6px 状态圆点（进行中绿 / 受阻琥珀 / 其它灰，饱和度 ≤60%）；
   - 错误 / 受阻文字（状态色 token）；
   - P0 的极小优先级文字。
   其余一律用文字层级表达：primary 100% / secondary 65% / tertiary 45%。
2. **字号收敛为 5 档**：20（页面标题）/ 15（区块标题）/ 13（正文与卡片标题，600）/ 12（说明）/ 11（元信息）。不使用 9–10px 正文（状态点旁数字 ≥10px）。
3. **卡片扁平化**：背景 `bg-layer-1`（或 base + 0.5px hairline），圆角 12，内边距 12–14，卡片间距 8px；**无阴影**，hover 只换背景 / 边框，不位移、不发光。
4. **去掉盒子**：统计用一行文字，不用彩色 KPI 卡；AI 研判是普通段落，不是彩色提示框；筛选用文字按钮 / 下拉，不用彩色 chips。
5. **一屏一主操作**：看板头部只留「搜索 + 扫描图标 + ⋯ + 新建」；抽屉底部只留「继续此任务」主按钮 + ghost「打开会话」+「⋯」。
6. **层次靠留白与字重**：区块间距 ≥24px；分隔线只用 0.5px 横线且仅用于抽屉内分节。
7. **深浅色一致**：所有颜色来自 token 或由 token 派生；不出现只在单一主题下可读的颜色。

## 4. 布局与信息架构

### 4.1 全页看板

```
任务看板                                     [搜索] [扫描] [⋯] [新建]
10 项 · 3 进行中 · 1 受阻 · 4 完成 · 上次扫描 刚刚      ← 12px secondary 单行
────────────────────────────────────────────────────────
待办 2            进行中 3           受阻 1           已完成 4      ← 列头 12px/600
 卡片               卡片               卡片             卡片
```

- 标题为「任务看板」，不出现大 logo / 英文品牌标识。
- 工作区筛选收进搜索旁的下拉；筛选弹层为 DSH 菜单风格（12px，行高 32，无彩色）。
- 扫描状态显示在统计行末尾（「扫描中 3/28」+ 取消链接），不用大进度条。
- 空态：一句说明 + 文本按钮「立即扫描」。

### 4.2 卡片（高度 ≤92px，三层信息）

```
标题（13px/600，最多 2 行）
工作区 · 3 小时前                              P0 · 5/8
进度线（2px，neutral 45% → 完成度 70%）
```

- 只保留三类信号：**标题**、**一行元信息（工作区 · 时间）**、**右侧极简指标（优先级 / 子任务进度或问题数）**。
- 移除：优先级彩色徽标、问题红色徽标、AI/规则彩色徽标、目标摘要、标签、彩色进度百分比。
- 完成态卡片：标题降到 65% 不透明度，无进度线。
- 受阻 / 问题：卡片上最多一个 `state-warn` 小点，说明放在抽屉里。

### 4.3 任务抽屉（参照 DSH 文档预览面板）

- 宽 520–560px；背景 `bg-layer-1`；左侧 0.5px hairline；无整屏模糊遮罩。
- 头部 48px：关闭 / 返回 + 「任务」小字 + 标题（15px/600，可两行）+ 右上「⋯」。
- 内容顺序：
  1. 一句话状态摘要（点「编辑」进入行内编辑）
  2. **关键事实**（默认 3 条，其余「展开全部 N 条」）
  3. **子任务**（复选列表，行高 30；新增用行内 input；可「从会话导入待办」）
  4. **问题 / 下一步**（合并列表，错误只用文字色）
  5. **会话**（标题 + 状态 + 「打开」）
  6. **产物**（列表行，hover 下划线，点击在 DSH 文档预览中打开）
  7. 折叠区：证据 N / 历史
- 底部 sticky bar：主按钮「继续此任务」+ ghost「打开会话」+ ghost「⋯」。
- 编辑态才出现「保存 / 取消」，展示态不铺表单控件。
- 关闭：×、Esc、点击外部、浏览器返回手势均可。

### 4.4 「继续此任务」弹窗

- 宽 520px；标题 15px/600。
- 目标为两行单选：「原会话继续」「同工作区新会话」，行高 36，选中用背景层 + 1px 边框，不用彩色。
- 提示词 textarea：等宽 12px、`bg-base`、0.5px 边框、圆角 8、约 8 行。
- 底部：ghost「取消」「仅复制」「AI 润色」+ 主按钮「放入会话」；说明文字 11px tertiary。
- 成功：关闭弹窗与抽屉，切到目标会话，提示「提示词已放入输入框，确认后发送」。

### 4.5 右侧栏形态

- 无品牌头；顶部一行统计摘要（11px）+ 扫描图标 +「⋯」。
- 状态切换用 DSH 视图 tab 文字样式，不做彩色胶囊。
- 三档自适应：
  - **窄（约 420px）**：单列卡片 + 状态分段切换；
  - **中（约 500–740px）**：2×2 列或紧凑多列；
  - **宽（≥740px）/ 全屏**：四列完整看板。
- 抽屉在侧栏内覆盖整个面板，并带返回箭头。

## 5. 响应式与尺寸

| 场景 | 宽度 | 要求 |
| --- | --- | --- |
| 全页看板 | 1680px | 四列、无横向溢出 |
| 全页看板 | 1280px | 四列可用，卡片高度 ≤100px，标题最多两行 |
| 右侧栏 | 420px | 单列 + 状态分段，标题不截断到不可读 |
| 右侧栏 | 756px | 紧凑四列或分档布局 |
| 右侧栏全屏 | 视口宽度 | 与全页看板一致，可退出 |

## 6. 交互规范

| 交互 | 规则 |
| --- | --- |
| 卡片点击 | 打开抽屉；拖拽换列时原卡片半透明，目标列 1px 边框高亮 |
| 键盘 | `/` 聚焦搜索，`n` 新建，`Esc` 关闭最上层浮层；对话框内 Enter 提交、Esc 取消 |
| 筛选 | 工作区 / 优先级 / 来源 / 标签 + 关键词搜索；筛选条件记忆到 localStorage |
| 打开外部目标 | 打开会话 / 产物 / 终端后自动收起抽屉，让用户回到目标 |
| 轮询 | 4 秒轮询 `/state`，页面隐藏时暂停；扫描中加快刷新，静默更新不闪烁 |
| 写操作 | 乐观更新 + 失败回滚 + 轻量 toast |
| 首屏加载 | 用 2 行文字占位，不用灰色块阵列 |

## 7. 可读性与无障碍

- 正文对比度 ≥ 7:1，按钮文字 ≥ 4.5:1（浅色与深色都验证）。
- 焦点环使用 DSH focus token，键盘可完整操作。
- 尊重 `prefers-reduced-motion`：所有动效在减少动效偏好下关闭。
- 状态不只靠颜色：受阻 / 错误同时有文字说明；图标的按钮带 `aria-label`。
- 中文优先排版：标题不强制英文字体；数字与代码用等宽字体 token。

## 8. 验收清单

- [ ] 与 DSH 自带页面并排比较：灰度、字号层级、留白、按钮形态一致。
- [ ] 页面无大面积彩色（除状态点与错误文字）。
- [ ] 1680 / 1280 / 右栏 420 / 右栏 756 / 全屏均无溢出。
- [ ] 深色 / 浅色各一套截图，无明显突兀色块。
- [ ] 头部只有 3 个图标 + 1 个主按钮；抽屉底部只有 1 个主按钮。
- [ ] `/`、`n`、`Esc` 快捷键生效；筛选条件刷新后保留。
- [ ] 控制台无 error / 404，无 loading 闪烁。
- [ ] 减少动效偏好下无动画。
