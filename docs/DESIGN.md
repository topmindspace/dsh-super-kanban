# 看板设计与交互

看板与 DSH 共用主题、文字层级和焦点样式。常用动作放在操作对象附近。卡片优先展示任务名称、阶段、运行或阻塞，以及最近活动。详情承载验收、来源和编辑。

## 工作区、项目、任务与会话

| 概念 | 来源 | 关系 | 在界面上 |
| --- | --- | --- | --- |
| 工作区 | DSH 的工作目录，自动出现 | 包含会话。每个任务属于一个工作区 | 「项目」页的工作区项目、范围下拉的「工作区」分组 |
| 项目 | 用户自建 | 可收纳多个工作区的任务。一个任务最多归入一个项目 | 「项目」页的自建项目、范围下拉的「自建项目」分组 |
| 任务 | AI 扫描会话生成，或手动新建 | 关联一条或多条会话，其中一条是主会话 | 任务卡、列表行、任务详情 |
| 会话 | DSH 的对话，实际执行工作 | 为任务提供进展、证据和交付物 | 任务详情的「会话」区、各处的「打开会话」入口 |

- 卡片、列表行、悬浮看板和任务详情用同一种写法显示归属：`工作区 › 项目`。只有工作区时显示工作区。
- 范围下拉首项是「全部范围」，可以选一个工作区或一个自建项目。右侧看板另有「当前会话 / 全部会话」切换。
- 「项目」页开头用一句话说明工作区、自建项目、任务与会话的关系，两个分组的标题旁标注来源。

## 三种形态

同一块看板有三种形态，同一时刻只显示一种。

| 形态 | 适合 | 进入方式 |
| --- | --- | --- |
| 全局看板 | 规划、整理、回顾，使用全部视图 | 左侧栏「任务看板」，或任一处的形态切换 |
| 右侧看板 | 边执行边跟进，默认只看当前会话的任务 | 会话页头的看板图标，或形态切换 |
| 悬浮看板 | 随手查看、验收、记一条待办、快聊 | 点常驻的悬浮入口，或形态切换 |

- 打开全局或右侧看板时，悬浮面板收起。打开悬浮看板时，界面回到会话并关闭右侧的看板标签页，其他标签页保持原样。
- 悬浮入口默认开启，在会话界面常驻，数量都为零时也显示。全局或右侧看板正在显示、或有对话框打开时，入口暂时让位。DSH 收起右侧栏后入口重新出现。
- 入口可拖动：上下调整高度，松手后吸附到左侧或右侧边缘，位置会被记住。右键菜单依次为展开悬浮看板、打开右侧看板、打开全局看板、快聊、移到另一侧、回到底部（移动过才显示）和隐藏悬浮入口。隐藏后出现带「撤销」的提示，之后可在会话页头的看板菜单或「看板设置 → 显示与入口」重新显示。
- 入口有圆形图标（默认）、紧凑胶囊和状态条三种样式。圆形图标用角标显示首个非零类别的数量，有任务运行时带绿色圆点。胶囊显示非零类别，状态条显示所选的全部类别。可选「空闲时隐藏入口」。
- 会话页头的入口分两部分：看板图标按默认形态打开，旁边的小箭头打开菜单，可选择形态（并记为默认）、打开快聊、显示或隐藏悬浮入口。
- 看板工具栏用三个图标切换形态，当前形态高亮。

## 悬浮看板

- 面板默认 540×720px，可放大到约 860px 宽、接近整窗高度，也可固定（固定后点击面板外不收起）。面板展开时入口隐藏，收起后回到原位。
- 类别固定为待验收、待处理、运行中和最近，不受「入口上的数量」影响。打开时停在第一个有内容的类别。筛选框筛选当前类别。
- 待验收按交付时间排序，缺少交付时间时用会话活动时间。验收条件与交付物入口相邻。待处理会话逐条提供入口，运行中先显示三项，可展开全部。「最近」列出近期全部任务，可打开会话或继续任务。
- 标题打开全局看板里的任务详情，按 Command 或 Alt 点击标题打开主会话。行内按场景提供「打开来源」「打开会话」或「打开运行会话」，以及「查看交付物」「继续」和「确认验收」，待审批或待回答的会话逐条有按钮。续做草稿可编辑，验收沿用任务详情的资格和版本检查。
- 待审批条钉在悬浮入口上方：会话一轮结束（`turn/end`）后出现一张卡片，点卡片本体直接回到那条会话；悬停卡片右侧出现绿色对号，点它才算「已完成」。不点就一直保留，刷新或重启后仍在。卡片左侧是工作区首字的彩色圆标（按工作区 id 固定取色，超出调色板后循环），右侧是会话标题（取侧栏展示标题，缺失时回退任务标题），下面一行是工作区/目录名和相对时间；标题放不下时静止显示省略号，悬停改为横向跑马灯并带两侧淡出遮罩。只有它自己的会话正在运行、等你回答、或就是你当前打开的那条时，这张卡会先收起（同一任务上其他关联会话的活动不会把它藏起来，对号也仍可点），切走或闲下来再回来，直到点对号。当前会话的卡收起后，入口上方保留一颗悬浮对号，点它就能在会话里直接完成验收。默认显示三张，其余折叠为「还有 N 项」；展开面板时整条让位。
- 底部的「随手记」输入框回车即新建一张待办任务。任务归到当前会话所在的工作区，不关联会话。
- 页头按钮依次为快聊、固定、放大、停靠到会话右侧、打开全局看板和收起。

## 全局与右侧看板

- 全局看板提供四列。窄容器使用单列与状态切换，视图下拉保留范围和当前会话切换。断点按面板容器宽度计算。
- 工具栏保留扫描、模型、快聊、设置、形态切换和新建入口。窄栏把搜索收进筛选，模型等常用操作保留图标和可访问名称。
- 扫描按钮显示进度，可取消和重试。最近结论在按钮提示及维护视图查看。会话运行来自 DSH 原生状态，运行标记同时使用文本和颜色。
- 每列独立滚动，每页 30 张卡。完成列可以折叠，折叠时仍可拖入。列表支持批量操作，项目卡可直接打开相应看板或日程。

## 项目、任务与验收

- 工作区自动形成项目视图，覆盖同一工作区的任务。自建项目通过任务归属组织工作，可以跨工作区，保留名称、备注、到期日、可选自动归入和归档。日程按未完成任务的到期日组织。
- 项目时间线按本地日期倒序显示任务历史、会话证据和带时间戳的交付。相同来源事件只显示一次，可打开任务或对应会话。默认显示近期事件，支持查看历史或全部时间。
- 活跃周期默认 30 天。旧自动任务进入历史视图。手动、置顶、运行中、待会话交互以及有到期日的未完成任务留在近期任务视图。时间线按事件时间切分。
- 抽屉优先展示目标、验收条件、当前阻塞和主交付物。任务证据与文件显示来源会话。待审批、待回答和待审阅从「待处理」打开原会话。
- 任务与产物的右键菜单提供同一组可见的快捷操作。操作支持方向键与 Esc，菜单关闭时恢复触发位置的焦点。
- 用户编辑时保留草稿。其他窗口或扫描更新了不同字段时合并，同一字段冲突时显示可选处理动作。
- 「继续此任务」预览要放入的提示词。用户选择关联会话或新会话，确认后只填入 DSH 输入框，由用户发送。

## 模型与快聊

- 工具栏显示模型名称，窄栏图标悬停时可查看模型。快聊与设置内的「切换模型」打开同一选择弹窗。
- 选择列表按提供方分组，首项为「跟随 DSH 默认」。支持手动刷新与读取失败后的重试。已保存模型暂时缺失时，继续显示该选项并解释可用的处理动作。
- 点「应用模型」后保存。扫描、重新研判、润色和快聊在新的调用中使用该模型。选择弹窗可在快聊内打开，保留输入和进行中的回答。
- 快聊是一个全窗口弹窗，可从看板工具栏、悬浮看板、悬浮入口的右键菜单和会话页头菜单打开。
- 模式用一排按钮切换：问答、写提示词、解释、总结、润色、译成中文、译成英文。问答把同一模型的最近几轮作为上下文，其余模式每次只处理当前输入。全部回答显示在同一条记录里，非问答的提问带模式标签。
- 回答按 Markdown 显示标题、列表、引用、行内代码、代码块和 http(s) 链接，代码块可单独复制。
- 每条回答可复制、放入当前会话的输入框（由用户发送）、存为待办任务（问题作标题，回答存入备注），最后一条可重新生成。新回答成功后才替换原回答，失败或被停止时保留原回答。
- 任务详情的「就此任务快聊」把任务的目标、验收条件、关键事实、问题和下一步作为参考资料带入问答。输入框上方显示参考任务，可随时移除。
- Enter 发送，Shift + Enter 换行，Esc 关闭，输入法选字时按 Enter 不发送。流式回答可停止，已收到的部分保留。停止或失败时保留输入，并提供「重试」。向上滚动查看旧回答时尊重滚动位置。
- 记录只保存在当前窗口的内存里，不写入磁盘，关闭弹窗后再次打开仍在。刷新窗口或点「新对话」即清空。换模型后的第一条问答开启新的上下文，旧回答仍可查看。

## 设置

「看板设置」分三组：显示与入口、AI 与扫描、范围与数据。显示与入口排在最前，包含默认看板形态、悬浮入口开关、入口样式与位置、入口上的数量、空闲时隐藏入口，以及悬浮面板的大小和固定。「入口上的数量」只影响入口，不影响面板的类别。显示偏好保存在浏览器本地（localStorage），不随备份导出。

## 可访问性与验收

浮层应有可读的标题、明确的首焦点和可预期的退出动作。用键盘走一遍新建、编辑、模型切换、快聊发送和停止，以及悬浮入口的展开、右键菜单和隐藏撤销。检查 1280px 全局看板、400px 窄屏、深浅主题及右侧看板。仅在状态变化时通过读屏提示进度，流式文本逐段更新。
