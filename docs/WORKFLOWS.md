# 日常使用

Super Kanban 把 DSH 会话里的工作整理成任务。会话负责执行和审批，看板负责跟进状态、安排交付和保留依据。

## 选一种看板形态

看板有三种形态，同一时刻只显示一种，随时可以切换。

- **全局看板** 占满主区域，适合规划、整理和回顾。从左侧栏的「任务看板」进入。
- **右侧看板** 停靠在会话旁边，默认只看当前会话的任务。点会话页头的看板图标进入。
- **悬浮看板** 悬浮在会话之上，适合随手查看和验收。点会话界面常驻的悬浮入口展开。

切换入口有三处：看板工具栏的三个形态图标、会话页头看板图标旁的小箭头、悬浮入口的右键菜单。悬浮入口默认显示，可以拖到顺手的位置。不需要时右键选「隐藏悬浮入口」，之后在会话页头的看板菜单或「看板设置 → 显示与入口」重新显示。

## 跟进并行会话

1. 在全局看板看整个工作面。在会话中打开右侧看板，按需切换「当前会话」范围。
2. 切到「待处理」。审批、提问和方案审阅会显示具体会话入口。点对应会话处理请求。若出现「可能同时修改」，先看涉及的文件和会话。
3. 想在会话里随时查看进展，展开悬浮看板。面板固定有待验收、待处理、运行中和最近四个类别，以及一个筛选框。运行中先显示三项，可展开其余任务。入口上显示哪些数量，在「看板设置 → 显示与入口」的「入口上的数量」选择。
4. 想到一件要做的事，在悬浮看板底部的「随手记」输入框写下标题并回车。它会成为当前会话所在工作区的一张待办任务，不关联当前会话。

## 从交付到验收

1. 打开「待验收」卡，先核对验收条件和主交付物。悬浮看板里的「查看交付物」会用交付来源会话打开文件。「打开来源」可跳到对应会话继续查看上下文。
2. 满足验收条件时点「确认验收」。看板记录人工验收并锁定状态。若验收前任务已更新，先读最新记录再确认。
3. 需要补做或让 AI 辅助核验时，点悬浮看板里的「继续」，或任务详情里的「继续此任务」或「生成核验草稿」。选择工作目的与目标会话，模板带入验收条件、关键事实、未完成事项与交付。检查并编辑草稿后放入输入框，由你发送。已有草稿会保留，可复制新内容手动合并。
4. 任务适合换会话时，在续做弹窗选择「新会话」与目标工作区。放入草稿后，看板会尝试关联新会话，后续进展归回同一张卡。

## 管理工作区项目和跨工作区项目

- 工作区来自 DSH 的工作目录，自动出现。项目由你创建，用来把一个或多个工作区的任务归到一起。任务在会话里执行，一张任务卡可以关联多条会话。卡片和详情用「工作区 › 项目」显示任务的归属。
- 「项目」自动列出已纳入看板的工作区。一个任务可同时出现在所属工作区和自建项目。需要跨工作区整理时，新建自建项目，再在任务详情或列表批量操作里调整归属。
- 从项目卡打开「看板」看分工状态，打开「日程」看逾期与到期事项，打开「时间线」按日期回看状态、会话证据、交付和人工变更。点任务标题进详情，点来源进会话。
- 「近期」默认覆盖过去 30 天的活动。手动、置顶、运行中、待会话交互和已排期未完成的任务也留在近期任务视图。时间线按事件日期切分，任务仍在近期时，其旧记录可在「历史」查看。
- 增量扫描使用设置里的活跃周期。旧会话恢复活动后重新纳入。需要为尚未建卡的旧会话补扫时，打开「维护 → 扫描全部历史」。扫描仍受工作区范围、忽略清单和 AI 预算约束。

## 用快聊处理零碎问题

快聊适合不值得开一条会话的小事。从看板工具栏、悬浮看板、悬浮入口的右键菜单或会话页头的看板菜单打开。

1. 选一个模式。「问答」可以连续追问。「写提示词」「解释」「总结」「润色」和两个翻译模式每次只处理当前输入。
2. 输入内容，按 Enter 发送，Shift + Enter 换行，Esc 关闭。输入法选字时按 Enter 不会发送。回答过程中可以停止，已收到的部分会保留。失败时输入仍在，可点「重试」。
3. 用回答下方的操作接着做事。「放入会话」把内容填进当前会话的输入框，由你检查后发送。「存为任务」新建一张待办，问题作标题，回答存入备注。「重新生成」重做最后一条，新回答成功后才替换旧回答。
4. 想围绕某张任务提问，在任务详情底部的「⋯」里选「就此任务快聊」。任务的目标、验收条件、问题和下一步会作为参考资料随问题发给模型。输入框上方可以移除参考。

一个常用组合：用「写提示词」把一句想法整理成任务提示词，点「放入会话」，在会话里确认后发送。

快聊记录只保存在当前窗口的内存里，不写入磁盘。关闭弹窗后再打开仍在，刷新窗口或点「新对话」即清空。

## 使用模型与维护数据

- 先在 DSH 设置中配置模型，再在看板工具栏选择模型。扫描研判、重新研判、草稿润色和快聊共用选择。扫描可用本地规则运行。
- 看板优先把已关联任务交给 AI 作为研判上下文，同工作区其他候选按最近的会话活动排序。需要固定状态、标题或优先级时，在任务详情锁定对应字段。保留人工判断的依据可写入项目备注、任务备注或验收条件。
- 在「维护」查看最近扫描结果与存储状态，可导出备份、预览恢复、找回删除任务和撤销合并。

遇到入口、版本、扫描和文件预览问题时，参阅 [常见问题与排障](TROUBLESHOOTING.md)。
