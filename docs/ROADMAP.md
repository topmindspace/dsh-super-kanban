# 产品路线图

Super Kanban 把多个 DSH 会话聚合成可追溯的任务。看板负责找到待处理、看清交付与验收依据、交接到下一次会话。会话运行、审批、工作树创建与执行编排由 DSH 或 Git 负责。

| 方向 | 0.6.x 范围 |
| --- | --- |
| 01 状态雷达 | 待处理与看板共用 DSH 原生运行和待交互状态，按当前范围计数。 |
| 02 跨会话聚合 | 显式关联会话和续做。主会话提供阶段依据，其他会话补充产物与证据。 |
| 03 智能交接 | 本地草稿包含验收条件、决策、未完成项和来源。放入新会话后才绑定。 |
| 04 并发修改提示 | 对同一真实工作树和文件的近期成功写入给出提示，并保留来源。 |
| 05 待处理收件箱 | 聚合审批、提问、审阅、失败、依赖和待验收任务。审批回原会话处理。 |
| 06 任务溯源 | 详情展示关联会话、文件和证据。Git 提交与 PR 链接等有可验证来源再接入。 |
| 07 搜索 | 任务摘要支持跨字段匹配。会话全文复用 DSH 检索能力，语义索引暂缓。 |
| 08 快照 | 看板 JSON 备份、会话草稿和 Git 提交分别承担恢复。跨环境回滚暂缓。 |
| 09 依赖 | 用户显式建立依赖，可从受阻任务打开前置任务。自动跨项目推断暂缓。 |
| 10 活动历史 | 任务内证据按时间和来源查阅。保留原始历史在 DSH。 |
| 11 成本与效率 | 展示看板研判调用、Token 和耗时。项目费用待可靠计费来源。 |
| 12 工作流 | 提供执行、排障、验收和交接模板。执行策略与编排沿用 DSH。 |

0.6.0 在隔离 DSH `0.2.2-rc.1` 使用合成会话验证了待交互、产物预览、人工验收和新会话续做关联。全页与侧栏覆盖浅色、深色和 390px 至 420px 的窄布局。最低支持版本与真实审批重连仍需独立验证。界面要求见 [设计规范](DESIGN.md)。
